# Pedagoji ön incelemeleri

`pedagoji-uzmani` ajanının (`.claude/agents/pedagoji-uzmani.md`) raporları. Dosya adı: `YYYY-AA-GG-kisa-konu.md`.

Bu raporlar **yapay zekâ ön incelemesidir** ve pedagoji ekibinin onayının yerine geçmez (PRD: "Uzman onayı"). Ekip bir öneriyi kabul ya da reddettiğinde karar [`../kararlar/`](../kararlar/README.md) altına yazılır.

Çalıştırma:

- `/pedagoji-inceleme <bölüm, oyun, dosya veya PR>` — rubriğe göre rapor
- `/pedagoji-danis <soru>` — kısa danışma cevabı
